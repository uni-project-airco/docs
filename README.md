## Preface

This documentation serves as an introduction and onboarding guide for developers and provides general project structure.

Here you will find:

- A high-level **system overview** and architecture diagrams
- Details of the **alpha prototype**, including hardware, firmware, and backend code
- Instructions for **deploying** the webserver to a custom domain on AWS
- How **PubNub** is used to connect IoT devices with the backend and mobile app
- A dedicated **security** section covering data at rest and in transit
- And many more
